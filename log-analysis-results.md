# Sample Web Access Log Analysis

## Project
AWS Internship Project

## Dataset Status
This report is a demonstration template. Results must be calculated from the final `web-access-logs.csv` dataset before submission.

## Metrics to Analyze
- Total number of requests
- Most frequently requested pages
- HTTP 4xx client errors
- HTTP 5xx server errors
- Peak request hour
- Number of unique IP addresses

## Conclusion
Web access log analysis helps identify frequently accessed pages, unsuccessful requests, and possible server-side errors.

**Note:** These are analysis objectives, not verified results from a running AWS server. The sample dataset is not actual AWS server traffic.
