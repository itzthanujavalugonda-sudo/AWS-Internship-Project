# AWS Internship Project

## Project Title
Custom VPC + EC2 Web Application + S3 Storage + IAM Roles + CloudWatch Monitoring + Automated Backup and Cost Control

## Project Objective
To design and implement a cloud environment using AWS services, including networking, computing, storage, access control, monitoring, backup, and cost management.

## Services Used
- Amazon VPC
- Amazon EC2
- Amazon S3
- AWS IAM
- Amazon CloudWatch
- Amazon SNS
- Amazon EBS
- AWS Budgets

## Project Status
Planning and initial setup.

## Implementation Plan
1. Create and secure the AWS account.
2. Configure a custom VPC and public subnet.
3. Deploy a Linux EC2 instance and host a demo website.
4. Configure S3 storage and IAM roles.
5. Set up CloudWatch monitoring and email alerts.
6. Create an EBS snapshot backup.
7. Configure budget alerts and analyze sample web access logs.

## Safety
AWS services may incur charges. Resources will be created only after reviewing their pricing and Free Tier eligibility.

## Evidence
Screenshots, architecture diagram, test results, and demonstration video will be added as implementation progresses.
