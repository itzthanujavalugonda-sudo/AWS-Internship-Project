About the Project

The objective is to deploy a web application using Amazon EC2, configure networking with Amazon VPC, store files in Amazon S3, and implement monitoring, security, backup, and cost control.

AWS Services

Amazon VPC

Provides an isolated cloud network.

Amazon EC2

Runs the website on a Linux server.

Amazon S3

Stores application assets and archived logs.

AWS IAM

Controls access to AWS resources.

CloudWatch

Monitors metrics and application logs.

Amazon SNS

Delivers monitoring alert notifications.
